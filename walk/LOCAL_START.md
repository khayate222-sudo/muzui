# 自分のPCでWALKを開く

`localhost` は、ブラウザを操作している端末自身を指します。クラウド環境の `localhost:3001` を、自分のPCのブラウザで直接開くことはできません。このクラウド環境には外部向けのWebプレビュー機能もありません。

## PCで動かす方法

1. Node.js 24以上をインストールしてください。公式配布元は https://nodejs.org/ です。
2. ZIPをダウンロードして**展開**します。圧縮フォルダーの中では実行しないでください。
3. `package.json` と `START_WINDOWS.cmd` があるWALKアプリのフォルダーで、PowerShellまたはターミナルを開きます。単独ZIPでは `WALK/`、GitHubのリポジトリZIPでは展開先の `walk/` です。
4. 以下を順に実行してください。

```sh
npm ci
npm run build
npm start
```

`Server listening` / `WALK ready` が表示されたら、**同じPCのブラウザ**で `http://localhost:3001` を開いてください。ターミナルは閉じず、そのままにします。終了するときはCtrl+Cを押します。

Windowsでは同梱の `START_WINDOWS.cmd` をダブルクリックしても、依存関係のインストール・ビルド・起動を順に実行できます。初回はインターネット接続が必要です。Windowsの実機検証は行っていませんが、起動コマンドのOS依存構文を取り除いています。

WindowsのエクスプローラーでZIPを開くと通常のフォルダーのように見えますが、まだ展開されていません。ZIP内の `.cmd` を直接実行すると、起動ファイルだけが一時フォルダーに取り出され、`npm ci` がロックファイルを見つけられなくなる場合があります。必ずZIPを右クリックして **「すべて展開」** し、その展開先の `walk` フォルダーで実行してください。修正版の起動ファイルは、必要ファイルの不足をnpm実行前に検出して案内します。

`.env` の作成は必須ではありません。DBとゲスト設定、管理者キーは自分のPCの `data/` に新規作成されます。ZIPにはクラウド側のDB・セッション・管理者キー・`.env` は含めていません。

## それでも接続が拒否される場合

- ターミナルに起動エラーが表示されていないか、またはターミナルを閉じていないか確認します。
- URLの `http` とポート番号 `3001` を確認します。ポート指定なしの `http://localhost` は別のポートを参照します。
- 起動した**同じPC**から開いてください。別PCやスマートフォンの `localhost` は、それぞれ別の端末を指します。
- `EADDRINUSE` は3001番ポートを別のアプリが使っているエラーです。`.env.example` を `.env` にコピーし、例えば `PORT=3101`、`APP_ORIGIN=http://localhost:3101` に変更して再起動します。

## 複数人が外部から開く場合

公開URLへのデプロイが必要です。WALKはリアルタイムAPIとSQLiteを使うため、静的ファイルを置くだけのホスティングでは動きません。永続ディスクとWebSocketが使えるNode.js/Docker環境を使用します。手順と公開前の確認事項は `README.md` と `docs/OPERATIONS.md` にあります。ZIPを作成しただけでは公開されません。
