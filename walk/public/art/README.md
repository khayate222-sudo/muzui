# WALKの描画素材

## 箱庭の素材

`world-buildings.webp`（1536×1024、透過の6種類の建物）、`world-station.webp`（1254×1254、透過の駅舎）、`world-coast.webp` と `world-garden.webp`（1536×1024、人物や建物を含めない地面）は、同じ手描きの世界観で新規に生成したWALK用のオリジナル素材です。WebPへの圧縮以外の画像加工はしていません。建物はアプリ側でフレームを指定して表示し、透明な画素を除いた入力判定にも使用します。夕暮れの色はアプリ内のCanvas描画で作ります。

背景の絵に実利用者や閲覧人数は含めていません。今回の表現と制限は `walk/docs/WORLD_GRAPHICS.md` を参照してください。

## 自室の素材

`room-evening.webp` はWALKの自室視聴画面用に生成したオリジナル背景（1536×1024）です。2026-10-15に検討した自室の参考画像から、人物・動物・テレビを含めず、実際の動画プレーヤーを配置できる背景として別途生成しました。WebPへの圧縮以外の画像加工はしていません。

駅や窓は静止した絵であり、実在する利用者・リアルタイムの人数を示しません。操作と実装範囲は `walk/docs/ROOM_WATCHING.md` を参照してください。
