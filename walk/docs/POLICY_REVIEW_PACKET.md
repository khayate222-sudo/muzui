# 規約・プライバシー文書を確定するための材料

2026-10-19。実装の説明と運営者の確認項目であり、承認済みの正式な規約ではない。運営者名・窓口・対象年齢・保存期間は未定。英語・簡体字・繁体字の正式文書は、実際の運営方法と対象市場を確認してから公開する。

| データ・機能 | 現在の実装 | 文書に反映して決めること |
| --- | --- | --- |
| アカウント | 表示名・アバター、別のログインID、scryptのパスワードハッシュ、復旧コードのハッシュ、セッション | 運営主体、対象年齢、アカウントの対応窓口。メールでの本人確認・自動復旧は未実装 |
| 閲覧と交流 | 開いている投稿をリアルタイム表示。名前等の一般公開は本人の同意に従い、非公開でも匿名人数には含む | 公開の説明と解除方法。架空の人気や実際の再生完了数を足さない |
| 保存・反応・マッチ度 | お気に入り、リアクション、双方が公開に同意した場合の共通点 | 公開対象と同意の撤回。恋愛相手の紹介や本人確認を実装済みとしない |
| 投稿・添付 | 公開投稿、本人だけの未公開アップロード、権限付き削除。画像・動画は25MB、活動写真を含む合計200MB | 投稿者の権利と許可、禁止行為、通報、削除、運営者に必要な配信許諾の範囲 |
| メッセージ・音声 | 承認した友達とのチャット。メッセージはSQLiteに保存し、E2E暗号化ではない。音声は招待・同意・マイク許可を必要とする | 会話の保持と削除、通報時の取扱い、TURN事業者、停止・問い合わせ手順。WALKによる音声録音機能はない |
| 活動・一日の記録 | 本人の自己申告、終了時刻、非公開が既定のメモ・写真。選んだ活動のみ共有 | 自己申告で実証ではないこと、共有の範囲。GPSによる自動追跡はない |
| 端末内 | 安全な保管領域のネイティブトークン、通常のアプリ保存領域の下書き・言語・趣味の選択 | 通常の下書き領域は暗号化保管庫ではなく、共有端末の注意と破棄方法。ストレージ消去・再インストールで失われること |
| 再試行の記録 | 直接投稿の識別子、内容のハッシュ、投稿参照。削除後も復活防止のため識別記録を残し、アカウント削除で消去 | 個別投稿の削除とアカウント削除の違い、保持方針の確認 |
| 外部サービス | ユーザー操作後のbilibili／抖音の公式埋め込み、YouTube／TikTokの公式プレーヤー、その他の元投稿リンク | 外部への接続・Cookie・IPなどの取扱いは提供元の文書も確認。外部の実再生、同期、永続的な再生許諾をWALKが保証しない |
| 運用情報 | 通常のHTTPアクセス、認証回数制限のハッシュ化した識別情報、管理・通報記録、非公開バックアップ | インフラ事業者、配備国、ログの保管・アクセス権・保持期間、事故時の連絡 |

本人は設定からJSONのデータ取得とアカウント削除を行える。JSONには添付一覧が入り、画像・動画・写真のバイナリは含まない。削除では本人の投稿・活動・部屋・添付と関係する会話等を削除し、相手の会話画面からも消える。添付ファイルの削除に失敗した場合は非公開の削除キューで再試行する。

過去のバックアップは通常のアカウント削除リクエストだけでは書き換えない。運営者が保管期間と安全な破棄、復元後に削除済みデータを再公開しない手順を決める。実際には提供しない期間・対応時間・暗号化・自動削除を文書へ書かない。

対象年齢が未確定のため、成人向けの同意や未成年向けの保護が済んだとは扱わない。課金・広告報酬・換金・カジノは現在有効ではない。公開前に、コンテンツ利用条件、UGCの対応担当、ブロック・停止・異議申し立ての窓口、正式文書の公開先を確認する。
