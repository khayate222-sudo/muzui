# 友達と、最初の5分を過ごす

最初の一本を選んだ人が、まだWALKでつながっていない友達を誘い、交流を承認し、別の同意を得て同期視聴する流れを実装する。運営が用意した短い描画動画も追加する。趣味の世界の大枠や、将来の建築・経済をまとめて増やす段階ではない。

## 初めての友達を誘う

1. 同期できる動画で「友達と、同じ瞬間を。」を開き、グループ内での名前・アバターの表示と同期に同意して始める。
2. 招待画面の「初めての友達も、この時間へ。」で、リンクを持つ人に自分の名前・アバターと動画のタイトルを見せることに同意し、リンクを作る。コピー・共有は自分で選ぶ。
3. 相手はリンクを開き、名前の設定を後にして進むか、ニックネーム等を設定する。招待者と動画を確認しただけでは、動画を開いた人数や同期グループに加わらない。
4. 相手が名前・アバターを招待者に見せて交流を申し込むことに同意し、動画へ進む。通常の公開設定は変えない。動画は個別視聴のままで、交流の承認待ちを表示する。
5. ホストの同期視聴の招待画面に、実際に届いた交流の申込みが表示される。「承認して同期視聴に招待」を選ぶと、既存の交流承認を行ってから既存の同期視聴の招待を送る。「今回は見送る」も選べる。
6. 相手が同期視聴への招待内容を確認し、参加への同意を選んでから同期する。相手の参加同意なしに再生や停止を操作しない。マイクは開始しない。

すでに交流が承認済みなら申込みを重ねない。相手が招待者から交流を申し込まれていた場合は、相手自身がその申込みを承認することを明示した上で進める。承認待ちの送信済みリクエストも重複させない。ブロックや利用停止を迂回しない。

「承認して同期視聴に招待」は二つの操作。承認できても招待が失敗した場合は、承認済みであることと招待をやり直せることを通知する。交流を自動で取り消したり、成功していない参加を成功と表示したりしない。

## リンクの範囲

- `#/together/{48桁のランダムな16進数}`。通常の投稿・世界・ルームの共有リンクとは別。URLのフラグメントを使用し、別のサイトへのリダイレクトを作らない。
- 作成できるのは実際に対象の動画の同期視聴をホストしているアカウント。新規作成時も共有への明示的な同意を必要とする。参加者がホストのふりをして発行することはできない。
- 15分間有効で、ホスト一人につき現在の一つだけ。新しく発行すると前のリンクは無効。ホストが取り消す、退出・切断する、別のグループを始める、動画が差し替えられる、利用停止になる等で使えなくなる。
- ホストの画面も期限後は作成画面に戻し、共有内容への同意を取り直せる。期限切れのリンクを取消できずに操作が止まる状態を避ける。
- リンクの確認時と、交流の操作前にサーバーで有効性を確かめる。相手がブロックされている場合は利用できない。
- トークンのSHA-256だけをサーバーのメモリに保持し、DBには保存しない。サーバー再起動でも失効する。確認・取消APIのURLに含まれるトークンはFastifyの通常リクエストログへ出さない。
- リンクが与えるのは、ホストが同意して共有する名前・アバター・動画のタイトルを確認する入口だけ。フレンド承認、同期への参加権、個人ルームの公開権限、現在地・視聴履歴・他の参加者の閲覧権を与えない。
- 確認画面では5秒ごとに有効性を再確認する。古い通信結果で新しい確認結果を上書きしない。操作時も有効性を再確認し、最終的な交流・参加の判定は既存のサーバー機能で行う。

通常の閲覧者一覧は引き続き公開への同意に従い、人数は実際に投稿を開く人の数。グループ内での表示への同意と、一般公開への同意を混同しない。リンクを確認しているだけの人や、現実の活動中の分身を閲覧人数へ加えない。

## 今回追加する6本

既存の七本の風景映像（各12秒・無音）を残し、次のオリジナル描画アニメーションを追加。各32秒、960×640、H.264＋AAC。映像・合成音は今回のコードから生成している。実写、実在の作家の手描き作業の記録、他の映画や楽曲の転載ではない。物語はフィクションで、架空のユーザー投稿や交流記録として表示しない。

| 世界 | 映像 | 見終わったあとの問い |
| --- | --- | --- |
| アート | 一緒に描こう、小さなマグ。 | このマグ、何色にしたい？ |
| アート | 拾った葉っぱを、一枚だけ。 | 今日、持ち帰りたい色は？ |
| アート | 窓の向こうに、好きな街を。 | この窓辺に、何を置きたい？ |
| 発見 | 珈琲が冷める前に。 | 誰に「また、ここで」と伝えたい？ |
| 発見 | 雨の向こうに、ひとつの灯り。 | 雨の日、どこで過ごしたい？ |
| 発見 | 帰り道の、紙ひこうき。 | 明日、どこへ寄り道しよう？ |

アートの3本は線・形・色が順に描かれる短いレッスン。発見の3本は湯気・便り・灯り・雨・紙ひこうきの動きと字幕で進む短編。最後の問いは動画内、棚、視聴画面に表示する。回答・感想を自動送信・公開することはない。サムネイルは実際にレンダリングした映像から作成する。

提供元は `WALK SHORTS · 描画アニメーション`、著者は `WALK STUDIO`。本編が六本揃った状態であり、クリエイターの投稿や多数の娯楽作品を揃えた状態とは区別する。外部作品の再生・ライセンスを今回確認済みとは扱わない。

## 保存と再生成

`shared/starter-shorts.ts` に題名・説明・問いと固定IDを保存。`public/films/walk-short-*.mp4` と `.jpg` を同梱するため、通常の起動にレンダラーや外部動画サービスは不要。元のプログラム描画は `scripts/starter-shorts-scene.html`、生成は `node scripts/render-starter-shorts.mjs`。既存のPlaywright、Chromium、FFmpegを使用する。必要なローカルHTMLはループバックだけで配信し、ブラウザの管理ポリシーを変更しない。

`seed_state=3` で一度だけ六本を投入し、既存の投稿、ルーム、保存、選定順を消さない。削除した短編や変更した選定順を再起動で復活・初期化しない。管理者は既存の動画の棚の選定順で変更できる。ジャンル選択を優先し、選定済みの通常動画・短編を、選定済みの風景映像より先に並べ、それぞれの選定番号順にする。同じ区分・番号のときは投稿日、IDで揃える。

固定IDと同梱メディアの組が一致する短編だけを、編集部提供の同期対象に追加する。任意の外部URLを同期可能にしない。YouTube／TikTokは公式プレーヤーでの個別視聴、映画配信は別工程。

## スマホ・ストアに残る確認

スマホ幅のブラウザでの確認、Android開発ビルド、iOS用素材への同期は、両OSの実機確認とは別。公開HTTPSサーバー、iOSのコンパイル、署名・ストア公開、OSごとの音声フォーカス・着信・スリープ・省電力状態での挙動は実機で確認する必要がある。クラウド内のlocalhostを公開プレビューとして案内しない。

現在の公開共有URLはWeb版を開く形式。インストール済みのネイティブアプリへ直接戻るUniversal Links／App Linksは、公開ドメインと署名に合わせる別工程。
