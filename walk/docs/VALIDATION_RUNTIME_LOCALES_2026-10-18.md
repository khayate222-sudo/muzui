# 招待・再生報告・地図の多言語検証（2026-10-18 JST）

## 変更

- 英語・簡体字・繁体字の47項目を追加し、辞書は1,319項目。同期視聴・ゲームのSocket.IOエラー、招待の期限切れ・取消・参加不可、通信の一般エラーを翻訳する。認可や人数制限、参加への同意条件は変更しない。
- 再生問題の報告欄の初期文を選択言語で表示する。利用者が編集して送った文章は原文のまま運営へ届く。世界の住人を通報するときの案内文も、世界名・IDを翻訳した全文に差し込む。
- 招待を受ける同意文を、申込み・承認・動画を開く場合ごとの全文にする。名前を含む待ち合わせ案内も全文で翻訳し、`$&` や `{name}` が名前に含まれていても再展開しない。
- 地図の案内看板、描画による駅の看板、他の閲覧者の状態を翻訳する。背景画像に描かれた文字、元の動画・題名・作者・利用者の文章は原文を保つ。
- Android/iOSの共有メニューへ渡すWALKの紹介文と見出しを翻訳する。共有する投稿名とURLは変更しない。

## 再実行

`walk/` で実行する。ブラウザーの実サーバー・Chromiumを起動できる環境が必要。

```sh
npm run typecheck
npm run lint
npm test
npx playwright test tests/e2e/international-safety.spec.ts tests/e2e/watch-links.spec.ts tests/e2e/bilibili-library.spec.ts tests/e2e/world-art.spec.ts tests/e2e/international.spec.ts
npm run native:sync
```

Androidは保存済みのJDK・SDK・Gradle設定で `./android/gradlew -p android --offline --no-daemon --max-workers=1 :app:assembleDebug` を実行した。環境設定の更新や新しい依存追加はない。
