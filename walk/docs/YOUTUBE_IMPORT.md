# YouTubeから、好きな世界へ（2026-10-17）

その後、ユーザーは供給元の優先を **抖音・快手の短い動画** に変更した。[現在の実装範囲](CHINESE_SHORT_VIDEO_SOURCES.md)を参照。このYouTube機能は維持するが、YouTubeを今後の最優先とする方針ではない。

URLから一本を持ち込む入口と、選んだチャンネルの新着を確認する画面を実装した。実YouTubeへのoEmbed・Atomフィード取得は、このクラウドのプロキシで403となり未確認。以下の実装と自動検証を、実サービスへの接続成功と区別する。[検証記録](VALIDATION_YOUTUBE_IMPORT_2026-10-17.md)を参照。

## 一本を登録する

1. 「投稿を集める」でYouTube動画・ShortsのURLを入力し、「YouTubeの情報を取得」を押す。
2. 公式oEmbedの題名・投稿者・チャンネルへのリンクと、YouTube画像ホストのサムネイルを確認する。題名と投稿者は編集できる。取得するだけでは投稿・お気に入り・閲覧人数を増やさず、動画も再生しない。
3. ジャンルと、そのジャンルの入口／奥の世界を選び、紹介文を添える。
4. 「確認して世界に置く」で公開し、お気に入りにも保存する。同じURLが既に登録済みなら元の投稿を保存して開き、題名・投稿者・公開先を上書きしない。利用できなくなった既存投稿は登録を拒否する。

情報取得に失敗した場合は、その旨を表示する。「情報を取得せず、手入力で続ける」を明示的に選べば登録できるが、取得済みとは表示しない。URLの変更は古い取得結果を破棄する。閉じた画面の取得結果は反映せず、明示して開始した登録の保存が完了しても、後から勝手に移動しない。

X・TikTokは引き続き題名・投稿者を手入力する。YouTubeとTikTokは公式プレーヤー、Xは元投稿リンクで扱う。外部動画ファイルの転載、外部SNSのログイン情報取得はしない。

## チャンネルの新着を確認する

管理画面で認証し、収集元のチャンネルID（`UC`＋22文字）またはそのチャンネルURLを登録する。`@名前`からIDを解決する機能は未実装。題名取得時の投稿者URLがハンドルの場合も、収集用IDが得られたとは扱わない。

既存の公開Atomフィード収集を使用する。「今すぐ取得」またはサーバー稼働中の定期取得で候補を保存し、「候補を確認」で出典・画像・公式プレーヤー・公開先を確認する。画面の確認チェックを入れてから公開する。確認前はプレーヤーを読み込まない。公開先を変更すると確認チェックを解除する。

これは管理画面の操作上の確認であり、著作権や配信条件の許諾を取得する仕組みではない。既存の管理APIは管理者認証の下で引き続き利用できる。既存の自動公開設定も維持するため、すべての投稿にこの画面での確認を強制する設計ではない。最初は自動公開をオフにする。自動公開はジャンルの入口へ、手動公開は選んだ同ジャンルの世界へ置く。登録済みのURLは移動・上書きせず、見送った候補・削除済み投稿の復活防止も維持する。

初期の候補チャンネルは接続未確認と表示し、操作なしに登録・公開しない。X・Instagram・TikTok・海外SNSの新着自動収集は今回追加していない。

## APIと接続先

- `POST /api/youtube/preview`：認証済み利用者から `{url}` を受け、YouTubeの固定oEmbed URLだけへ接続する。利用者が指定した任意ホスト・投稿者URL・返されたHTMLへアクセスしない。
- 応答は題名・投稿者・検証済みの投稿者URL・公式画像ホストのURL・取得時刻などに絞り、提供元のHTMLを描画しない。
- 取得は10秒、JSON本文64KiBまで。リダイレクトを追わず、利用者ごと毎分12回、同時8動画まで。成功を最大100件・10分だけメモリに保持し、同じ動画の並行取得をまとめる。失敗は成功としてキャッシュしない。
- `POST /api/imports` と管理の候補公開APIは、任意の同ジャンルの `worldId` を受け付ける。別ジャンル・存在しない世界への指定は拒否する。既存DBをそのまま使い、移行・依存追加はない。
- サーバーは `www.youtube.com`（oEmbed・フィード）、クライアントは `i.ytimg.com`（画像）・`www.youtube-nocookie.com`（埋め込み）へ接続する。実プレーヤーの配信では提供元の追加接続先や地域条件の確認が必要。

## 実接続と公開前の残り

この環境の設定下書きへ、上記3ホストと公式資料の `developers.google.com` を追加保存した。既存のパッケージ取得用プリセット・起動設定は維持した。下書きの保存は現在の環境への適用ではない。環境設定で変更を確認・保存し、環境を公開して反映した後、実際の動画URL・チャンネルIDで取得・画像・再生・制限時の案内を改めて検証する必要がある。

取得した題名・投稿者名は、確認・編集した投稿情報として保存する。画像は公式URLを参照し、動画ファイルはダウンロードしない。商用運用前には現在の提供元規約・表示と保存条件・削除への追従・地域制限を確認する。今回、外部の最新規約を取得して適合を認定したわけではない。外部動画への報酬、広告の除去、YouTubeの同期再生、映画配信は実装範囲に含めない。
