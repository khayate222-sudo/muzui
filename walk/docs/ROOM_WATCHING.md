# 窓辺で見る：自室の視聴モード

参考画像の「部屋の窓越しに夕暮れの広場を見る構図」を、実際の投稿プレーヤーと組み合わせた最初の実装です。自分のルームで、窓の向こうの駅と室内の画面を眺めながら投稿を見られます。

## 使い方

1. 「みんなのルーム」または「ルームを探す」から、自分のルームを作成する。
2. 保存・いいねした投稿、または自分のWALK投稿を配置して保存する。非公開のまま利用できる。
3. 自分のルームカードの「窓辺で見る」を選ぶ。箱庭として訪問した後にも、上部の操作列から選べる。
4. 部屋の下にある投稿の棚から見たいものを選ぶ。選んだ投稿を実際に開くまで閲覧者にならない。
5. 室内の「大きく見る」または上部の「大画面で見る」で拡大。「部屋と見る」で戻る。「箱庭へ戻る」は投稿を開いたまま通常の箱庭＋視聴パネルへ戻す。
6. 「閉じる」またはEscapeで視聴を終了する。ルームの箱庭へ戻り、閲覧状態を解除する。

部屋に投稿がないときは、配置方法と編集へのボタンを表示する。勝手におすすめ動画を再生したり、架空の閲覧人数を追加したりしない。編集では既存のルーム一覧から対象の「配置を編集」を選べる。

## 今回実装したこと

- 手描きの夕暮れの部屋を背景に、実際の動画・画像・公式埋め込み・テキストの案内を表示する。Xなど埋め込み対象外の投稿には元のサービスへのリンクを残す。
- 自室の表示は現在のルームの持ち主だけに提供。公開ルームの訪問者には既存の箱庭・視聴パネルを提供する。ルームの公開設定やサーバーの入室権限を変更しない。
- 棚はそのルームに実際に配置された、現在読み取れる投稿のみ。投稿選択と「次へ」は既存のサーバー確認付き移動を使う。ルーム内に次の投稿があればその座標へ移動し、投稿と人数を更新する。
- 室内・大画面・箱庭で同じ動画／iframeを保持し、切替によって作り直さない。再生位置・一時停止・ホストの操作権を維持する。外部サービスの通信や再生許可は別途サービスに依存する。
- 実際に同じ投稿を開いている人数と、公開に同意した人だけの名前・アバター・リアクションを既存の表示で確認できる。部屋の背景には人や動物を描き込まず、閲覧者と誤認させない。
- 同期視聴は既存の招待・参加の同意を使い、室内表示を選ぶだけでは参加しない。個別視聴・自室への入室・同期グループは別の状態。
- 室内表示中と大画面中は背景のアプリを操作対象外にし、フォーカスを画面内に保つ。配置編集やプロフィールなどを上に開き、閉じたら元の画面へ戻れる。
- スマホは窓を上部に残し、動画を幅広く表示する。動画面に拡大のクリック判定を重ねず、再生操作と分けた「大きく見る」を用意した。YouTubeの室内プレーヤーには高さ200px以上を確保する。

## 絵と機能の範囲

`public/art/room-evening.webp` はこの機能用に生成したオリジナル背景をWebPに圧縮したもの。約413KiBでWeb・ネイティブのビルドに含める。過去の参考画像にある人物・猫・テレビの絵は含めず、アプリの実際のプレーヤーを重ねる。素材の新規依存パッケージ・外部配信サービスは追加していない。

窓の駅は静止した共通の夕暮れの背景。リアルタイムの駅、他ユーザーの居場所、実際の時刻を表示する窓ではなく、「背景」と画面に明記する。部屋の既存テーマ・配置した装飾がこの絵に反映される仕組み、家具の着せ替え、昼から夕暮れへの変化、外の世界を窓から直接操作する機能、自由なカメラは今回未実装。既存の投稿・装飾の配置編集は箱庭に反映される。

実際の動画・音声はユーザーの投稿や公式プレーヤーから再生する。ブラウザ・OSの自動再生制限がある場合は再生ボタンから開始する。大画面はアプリ内の表示切替で、OSの全画面再生やPicture in Pictureとは別。
