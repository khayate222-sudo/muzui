# 灯りの遊戯館と、暮らしのコイン

2026-10-19。駅の奥で友達と同じ卓を囲む体験と、コインの使い道・装飾の拡充を依頼された。現実の仕事・物品売買・換金は対象外のまま。

## 駅の奥の小さな遊戯館

駅の「駅の奥へ」、行き先一覧の「駅の奥の寄り道」、暮らし・コインの「友達と遊戯館で遊ぶ」から入る。IDは `venue:lantern`。趣味の大枠を増やす施設ではなく、駅につながる寄り道として扱う。親は駅で、パンくず・戻り道・場所の共有・友達への招待に接続する。投稿先のカテゴリーには追加せず、趣味世界を住人が育てる既存の方針を維持する。

木枠と石壁、植物、空の読書席、紙の灯りの工房、丸いゲーム卓が見える小さな館を一枚の風景として描いた。使用素材は [courtyard-lantern.webp](../public/art/courtyard-lantern.webp)。既存のゲーム世界の自作背景を参照したオリジナル生成素材で、人・利用人数・投稿は焼き込んでいない。夕暮れは同じ背景と住人に共通の陰影と入口の柔らかい光を重ねる。光の変更でマップを作り直さない。

光は既存の「時間に合わせる／放課後／夕暮れ」を使う端末ごとの表現。友達のタイムゾーンに関係なく会えるよう、夜間だけの入場制限や世界共通の営業時間にはしない。屋根・壁・玄関・看板から反応する。中央の建物は卓、右の工房はお店、左の戻り口は駅へつながる。背景を取得できない場合も画面の入口・戻る操作は使える。

## 同じ卓を囲む

月の卓と太陽の卓があり、各最大6人。場所への招待、着席への同意、一回ごとの準備を分ける。

1. 友達を遊戯館へ誘い、卓の名前も伝える。承認済みの友達への招待は既存の10分間の場所の招待で、受信者が確認して移動する。招待だけで着席・音声・同期視聴には参加しない。
2. 名前とアバターを同じ卓の参加者に表示することへ同意し、選んだ卓へ座る。画面には実際の参加者と空席だけを描く。同じユーザーの別画面から二重に座れず、別卓の参加者や残高を共有しない。
3. 各自が太陽／月と使う無料チップ1〜20枚を選び、準備する。この時点では引き落とさない。準備は取り消せる。異なる人が同時に準備しても互いの選択を消さない。
4. 全員が準備すると、参加者の誰かが一回だけ回す。サーバーで同じ二択の結果を決め、各自の選択・枚数に応じた増減を、全員分まとめて一つのDBトランザクションで記録する。片方だけ支払う・受け取る状態にしない。
5. 結果を一緒に見る。次の一回でも各自の準備が必要で、自動で続けない。席を離れる・世界を移動する・切断することで退出し、勝手に再参加しない。人数の変更で準備と一回の識別子を作り直す。

二択は各1/2。使った数を当たりなら加算、外れなら減算する。参加者間でチップを渡すポットではない。残高は本人だけが取得できる。同じ卓の人には同意した名前・アバター・準備した選択と枚数・その一回の増減を表示する。動画の閲覧公開設定や閲覧人数には加えない。

準備後に別の遊びでチップが減った場合は全員の精算を拒否し、誰からも引き落とさない。同じ一回を二人が同時に回しても一回分だけ記録する。ひとり用の操作とは識別子の名前空間を分ける。本人の直近10回の結果は「暮らし・コイン」のチップ履歴に残り、再読み込み後も取得できる。

卓の席・準備状態はサーバーのメモリにあり、再起動で終了する。精算済みのチップと結果はSQLiteに残る。未精算の準備を再起動・再接続で復元したり、自動で支払ったりしない。公開モードでは既存の `WALK_ARCADE_ENABLED` が既定オフで、年齢方針・保護・ストア申告の確認が済むまで遊びを有効にしない。実際のお金や景品はない。

## コインの行先

コインは「自分の居場所を作る」と「住人に手伝ってもらう」ために使う。日常的な動画視聴や基本の建築、部屋の維持に支払いを要求しない。

| 流れ | 増減の扱い | 現在の実装 |
| --- | --- | --- |
| 日次の無料受け取り | 新たに200コイン増える | UTC日付ごとに本人が一度受け取る。連続ログインの条件・失効なし |
| お店で家具・素材を解放 | その価格を消費する | 一度の解放で、本人のルームへ何度でも配置可能。置くたび・回収の費用なし |
| 依頼の募集 | 報酬を一時的に預かる | 1〜1000コイン、進行中10件まで。取消可能な段階では返却する |
| 依頼の完了承認 | 預かっていた分を相手へ渡す | 新しくコインを生まず、住人間で移る。二重支払いを拒否する |
| チップ・現金・投票権 | 経路を設けない | 購入・換金・外部送金・チップ交換・承認購入を行わない |

お店での消費と依頼の預かりを同じ「支出」に隠さず、本人限定の「コインの足あと」で直近20件を表示する。サーバー台帳から種類・増減・日時を返し、他人の履歴や内部の参照識別子は公開しない。

### 今回増やした装飾

| コイン | 装飾 |
| --- | --- |
| 100 | 紙の灯り、窓辺のクッション、小さなガーランド |
| 200 | 読書の椅子、古い置き時計 |
| 300 | レコードの小机、絵描きのイーゼル |
| 400 | 小さな水槽、星見の望遠鏡 |
| 600 | 花のアーチ |

既存の桜色・夜空色・銅色は各150コイン。お店は合計13商品、建築は無料の基本10種＋装飾10種。基本6色を維持する。100〜200コインは最初の日から選べ、300〜600コインはゆっくり貯める目標にする。限定販売、ランダム箱、維持費、家具の劣化を追加しない。

すべて部屋を飾るアイテムで、音楽再生、望遠鏡の操作、水槽の育成、家具に合わせた着座などは未実装。選んだ見た目をお店と建築プレビュー・実際の箱庭で共通の形から描く。購入前には価格と不足分、所有後には何度でも配置できることを表示する。ゲーム内コインでの解放であり、実課金ではない。

解放した家具は「ルームを開いて飾る」から自分のルームの「建築する」で選ぶ。未入手の家具・素材は画面で選択を止め、設計図や直接APIを使ってもサーバーが所有を検証する。設計図の共有で家具の使用権まで相手に移すことはない。既存の保存・8件の復元・競合保護を使う。

## 保存・配備と今後

追加依存や新しい環境変数、DBの削除は不要。0012〜0013の既存テーブルに装飾所有権と結果を記録する。既存の素材所有・部屋・投稿・履歴は維持する。本人のデータ取得、アカウント削除、SQLiteバックアップに接続する。新しい家具を含む保存は、この版のサーバーとクライアントを合わせて更新する。

今後の拡張は、同じ世界観の家具セット、衣装・身につける小物、住人が作るパーツと設計図、道具の操作や着座を別途設計する。共有区画の承認や投票権は販売しない。ユーザー作品の販売・価格・利用権は今回の依頼機能とは別に扱う。動画・広告報酬、実課金、ストア公開、実機確認を実装済みにはしない。
