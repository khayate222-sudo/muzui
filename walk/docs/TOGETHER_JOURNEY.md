# 同じ時間を過ごす、WALKの最初の一日

WALKは、同じ自分と人間関係が続く小さな生活世界を目指す。今回は、既存の駅・家・ゲームの世界を「一緒に過ごす」入口でつなぎ、実際に遊べる協力ゲームを加えた。固定の趣味カテゴリーや世界は増やしていない。

## 駅で待ち合わせる

画面上部の「一緒に過ごす」を開く。「待ち合わせ」では、駅への移動、駅の招待リンク、承認済みの友達への直接招待を選べる。駅にいるときは、従来の公開・ブロックの条件で表示できるオンラインの住人を案内する。活動中の分身や架空の人は加えない。

場所への招待は既存の10分間の招待を使う。相手が内容を確認するまで移動しない。「一緒に過ごす」の中にも受信した招待を表示し、通知画面へ戻らず行き先を確認できる。到着だけで投稿を開いたり、同期視聴・パーティ・マイク・ゲームに参加したりしない。

## 同じ家の窓辺で見る

「家で見る」から、訪問できる家の窓辺へ入るか、小さな家を作る。新規作成の公開設定は既定でオフ。名前と最初の投稿を選べ、投稿は自分のWALK投稿か、保存・いいねしたものに限定する。既存の個人ルームの作成・所有権・5室の上限を使い、公開や配置は従来のルーム編集でも変更できる。

公開ルームでは訪問者も窓辺の視聴モードを使える。非公開ルームに他人が入れるようにはしていない。公開ルームを訪問しても配置の編集権限は増えない。窓辺／箱庭／大画面で、同じ動画や公式埋め込みの要素を保持する。

部屋の棚から投稿を選ぶまでは閲覧人数に含めない。同じ投稿を開く人と、再生を合わせる同期グループは区別する。直接投稿動画の同期視聴は、既存の招待・双方の同意を使う。外部サービスの画面共有や動画の取り込み、外部動画の同期再生を追加したものではない。

窓辺の「この家に友達を誘う」から場所の招待を送れる。「視聴を終えて遊びへ」はこの画面の投稿を閉じ、次の行き先を選ぶ。ホストが同期視聴を終えると、ほかの人は個別視聴へ戻る。次の場所へ強制移動しない。

## 遊びに出かける

「遊びに行く」から既存のゲームの世界へ出かけるか、今いる家のテーブルを使う。ゲームの世界への友達の招待も、行き先の確認を必要とする。

最初の遊びは「星の切符あわせ」。12枚に隠れた6つのペアを、ひとりでも最大6人でも協力して探す。順番は固定せず、同じ場所の参加者が同じカードをめくる。不一致の2枚は短い時間見せてから伏せ、全ペアが揃うと新しい一局を始められる。進行中の一局を他人が勝手に初期化する操作はない。

- 名前・アバターをゲーム参加者に表示することに同意してから参加する。通常の閲覧公開設定は変えない。
- ゲームへの参加ではマイクをオンにしない。既に参加している音声パーティは、その既存の設定を維持する。
- この画面の投稿の閲覧を終了し、ゲーム参加者と投稿閲覧者を区別する。別のタブで実際に見ている投稿まで、閲覧状態を偽って消すことはしない。
- 1ユーザー1画面でゲームへ参加でき、別タブを人数に足さない。参加していない人にゲームの状態や参加者を配信しない。
- 配置はサーバーでシャッフルし、裏向きのカードの答えをクライアントへ送らない。現在の一局IDと更新番号を検査し、同時操作・古い画面・不正な位置の指定・連続操作を検証する。
- ゲームの趣味世界（住人が作ったゲームの子世界を含む）か、アクセスできる個人ルームに実際にいることを検査する。駅や活動先へ新しいゲーム世界を増設していない。
- 移動、切断、利用停止、ブロック、ルームの非公開化・削除で、参加資格を失った人をテーブルから外す。途中退出に金銭やゲーム上の罰則はない。
- 一局はメモリ上だけ。全員の退出・サーバー再起動で終了する。サーバー上のタイマーも終了時に片づける。通貨・報酬・ランキング・恒久的な成績には結びつけない。

## 先の世界

勉強や作業を一緒にする場所、討伐クエスト、自由な建築、住人が提供するものや仕事、希望する人同士の恋愛的な出会い、カジノは将来の方向として記録した。今回まとめて実装した機能ではない。カジノは本人が特に希望する場所であり、まず換金しない専用チップによる遊びを候補にし、収入・決済・課金と分けて設計する。
