## 再実行

`walk/` で実行する。サーバーを使う検証にはローカルポートとChromiumの起動権限が必要。

```sh
npm run typecheck
npm run lint
npm test
npx playwright test tests/e2e/international-admin.spec.ts
npx playwright test tests/e2e/international.spec.ts tests/e2e/youtube-import.spec.ts tests/e2e/douyin-player.spec.ts tests/e2e/walk.spec.ts tests/e2e/accounts-release.spec.ts --grep 'first video|language|account deletion|administrator|admin resolves'
npm run native:sync
```

Androidビルドには保存済みのJDK・SDK・Gradle設定を用い、`./android/gradlew -p android --offline --no-daemon --max-workers=1 :app:assembleDebug` を実行した。ツールの配置と環境変数はクラウド環境の起動手順を参照する。
