# 箱庭の見た目とスマートフォンの操作

最新のUI・世界別の演出・共有機能は [STYLE_AND_WORLD_DESIGN.md](STYLE_AND_WORLD_DESIGN.md) を参照してください。

## デザインの方向

WALKの中心は「同じ投稿を開く、本当にいる人との出会い」です。数字や住人を演出で増やさず、地図・実閲覧者・入口の見つけやすさを優先します。

共通の駅は夕暮れの空に浮かぶ小さな島。時計台、暖かい窓、青い列車と線路、庭と石畳から始まります。音楽とアニメは和風の梁やランタン、動画とゲームは未来の窓やネオン、RPGは結晶や城、アートは植栽のある工房という異なる風景を重ねます。住人が育てる世界の余地を残し、すべてを同じ作風へ寄せません。

建物・列車・床・樹木はPhaserのベクター描画で作成しています。場所選択のイラストとアプリアイコンも自作です。写真のような架空の利用者、外部作品の無断素材、偽のオンライン人数を使いません。世界ごとにテーマが異なっても、看板・影・屋根の読み取り方は共通にします。

## 判定と操作

- 扉だけでなく屋根、側面、前壁、看板を選ぶとその世界へ入れます。屋根の三角形の外にある空や、建物の影だけを押しても入口へ入りません。
- 共通の駅舎全体を選ぶと行き先一覧を開きます。画面の「行き先」でも選べます。
- 投稿パネルと他ユーザーのアバターも、表示位置と同じ位置で反応します。ContainerのdisplayOrigin補正を共通処理にしました。
- 短いタップは選択／移動、ドラッグは地図の見渡し、2本指のピンチは拡大縮小です。ドラッグ・長押しを入口へのクリックとして扱いません。
- 「自分の位置に戻る」はカメラを自分へ戻します。アバターを駅の座標へ強制移動する操作ではありません。
- マウス、タッチ、ズーム、パン後の実際のイベントで屋根・側面・看板・投稿・住人を検証します。DOMの別ボタンをクリックするだけでは地図判定の検証にしません。

## スマートフォンの画面

画面全体に収まる地図中心の構成にし、下にホーム・探す・保存・つながり・あなたを並べます。現在地、行き先、投稿、活動は地図の上側へ置きます。行き先の入口は横に送れるため、説明文やボタンで地図を押し下げ続けません。ノッチやホームインジケーターの余白を考慮します。

投稿は下から現れる視聴パネル、大画面モードへ切り替え可能。どちらにも公開同意済みの実閲覧者を表示します。フォームは指で操作できる大きさ、iOSで入力時に勝手に拡大されにくい文字サイズにしています。

## ストアアプリの方向

ユーザーの希望はPWAより **App Store・Google Play向けを優先** することです。既存のReact / PhaserをCapacitorのiOS・Androidプロジェクトへ組み込みます。ネイティブ版とブラウザ版は同じWALKサーバーのAPIとリアルタイム同期を使います。

ストアへの配布とネイティブ実機検証は、ブラウザのタッチ検証とは別工程です。構成・接続・必要な公開サーバーについては [NATIVE_APP.md](NATIVE_APP.md) を参照してください。
