# 駅・広場・移動先の手描きの箱庭

自室だけだった新しいアートの方向を、実際に歩ける箱庭へ広げた最初の実装。駅と発見の広場、趣味の世界とその奥、活動の部屋に共通の手描きの地面・建物・光を導入した。ルートの別サイトは変更していない。

## 今回の見た目

- 不思議な駅：赤い瓦、生成りの壁、時計塔、使い込まれた木、暖かな窓の駅舎。背後に海が見える石畳の庭。
- 発見の広場とその他の世界：紙のような質感の石畳と草地。木造の音楽の家、アートの工房、青い屋根の映像館、青い塔のゲームの城、苔と光のRPGの洞窟、紫の屋根の小さな城を入口として使い分ける。
- 音楽・アニメの和風、映像・ゲームの青い建築、RPGの岩や石など、世界の違いは建築・目印・色で残す。各世界に専用の巨大な街を作り終えたわけではなく、共通の地面と6種類の入口の原型を使う段階。
- 個人ルームの箱庭にも共通の手描きの地面を使う。既存の投稿と装飾の配置・編集は保持する。
- 移動先の中央には、その世界の建物を使った案内所を置く。「案内」の看板または建物全体から行き先を選べる。駅へ戻る入口にも、同じ時計塔の駅舎を使う。
- アバター、実際の投稿の看板、閲覧人数、活動中の分身は絵の背景と分けて描く。背景に架空の人や利用人数を描き込んでいない。

駅や建物・地面は新規に生成したオリジナル素材。自室の参考画像をマップ全面へそのまま貼ったものではない。斜め上からの基本視点を使い、素材と実際の投稿・アバターをPhaserの同じ座標上に重ねる。

到着直後は、自分の少し前にある建物と広場が見えるカメラ位置にする。スマホでは少し引いた画角にし、地面だけが映って到着先の建物が画面外にならないよう調整した。「自分の位置に戻る」では通常どおり自分を中心にでき、移動・ドラッグ・拡大縮小の操作は維持する。

## 放課後と夕暮れ

地図上部の「箱庭の光」で「時間に合わせる」「放課後」「夕暮れ」を選べる。「時間に合わせる」は端末のローカル時刻で6時から17時までを放課後、その他を夕暮れとして描く。天気やGPSを取得する機能ではなく、夜も暗くなりすぎないよう夕暮れの表現を使う。

時刻の境目は今回の実装上の初期値で、運営者と住人が決めた共有世界の時刻ではない。光はこの端末の見え方だけに影響し、他の人の設定やオンライン状態を変更しない。選択は端末のlocalStorageに保存し、保存できない環境でもそのセッション中は選べる。

夕暮れは地面と建物に淡い青紫の陰影を加え、街灯の光を表示する。Canvasレンダラー向けに色を変えた素材を場面の開始時に準備し、選択時に参照を切り替える。毎フレーム画像全体へフィルターを掛けず、光を変えるだけでマップ・アバター・動画プレーヤーを作り直さない。長いアニメーションや点滅を追加していない。

## 操作と描画の関係

- 入口の画像を透過部分つきの独立した素材として配置する。屋根・壁・入口・描かれた鉢植えなどの実際の不透明な輪郭と、行き先の看板を押せる。
- 画像の透明な空白や薄いにじみは押せる領域に含めない。描画サイズに合わせて元画像のアルファ値を調べ、半分以上不透明な画素を使う。拡大縮小・カメラ移動でも同じ変換で判定する。
- 以前の画像とは足元の絵が異なるため、ブラウザ検証の足元のクリック位置も、新しい絵の実際の段へ変更した。透明な場所を押せるように範囲を広げて合わせたものではない。
- タップとドラッグ・ピンチを区別する既存の処理を維持。行き先一覧、パンくず、戻る操作でも移動できる。
- 既存の投稿座標・ルームの配置・サーバーの移動確認・入室権限を変更しない。画像を取得できないときは従来のベクター描画と行き先操作を残す。

## 素材とスマホ

| 素材 | 用途 | 圧縮後の目安 |
| --- | --- | --- |
| `world-buildings.webp` | 3列×2段の透過入口素材 | 約498KiB |
| `world-station.webp` | 時計塔のある駅舎 | 約392KiB |
| `world-coast.webp` | 駅の海辺の地面 | 約503KiB |
| `world-garden.webp` | 他の世界とルームの地面 | 約505KiB |

使用する地面を読み込み、WebとiOS / Android向けの素材に同梱する。元の生成PNGは実行環境の `generated_images/` に残し、配布するアプリには圧縮した素材を使う。追加の画像配信サービスや依存パッケージは不要。スマホでは光の選択と現在地を地図上部へ並べ、行き先・視聴・下部ナビを維持する。

## 今回の範囲に含めていないもの

住人による共有世界の建築、家具パーツの自作・外部持ち込み、全アバターの描き直し、各世界の大規模な固有マップ、建物に沿った衝突や経路探索、ベンチや窓で自由に切り替える複数のカメラは引き続き未実装。既存の自室「窓辺で見る」は共通の静止した夕暮れ背景を使用し、今回の箱庭の光とは別。
