# 運用・改善チェックリスト

## 公開前に必要な設定と確認

- 独自ドメイン・TLS・永続ディスクを持つNode.js 24の単一インスタンスを用意し、APP_ORIGIN / COOKIE_SECURE / ADMIN_KEYを設定。秘密情報をGitに入れず、管理用のブラウザとキーを限定する。
- リバースプロキシのWebSocket転送、切断から再接続、外部2端末からの移動・閲覧人数・承認・チャットを実際のドメインで確認。プロキシを信頼する設定は現在無効。IPベース制限を変更する場合は信頼できるプロキシ範囲を明示し、任意のX-Forwarded-Forを信用しない。
- 権利・外部リンク・YouTubeの公式埋め込み許可を確認した実コンテンツを登録。初期のYouTubeサンプル5件は実動画再生未検証。元サービスの地域・年齢・追跡防止・埋め込み制限が影響する。
- 運営者・プライバシーポリシー・利用規約・通報窓口・削除依頼手順・保存期間を定める。通報は保存・閲覧まで実装、担当者への自動通知・対応完了ワークフローは未実装。
- DBの暗号化、ディスクアクセス権、オンラインバックアップと復元試験、ログの保持と監視を設定。メッセージはDBに平文保存し、エンドツーエンド暗号化ではない。
- npm auditとコンテナスキャン、TLS・CSP、負荷試験、ゲスト作成悪用・通報スパム対策を公開規模に合わせて再確認する。

## 現在の制約と改善項目

- ゲストIDはサーバー発行のCookieに紐づく。複数タブを重複集計しないが、Cookieを削除したり別端末を使う同一人物を一人だと証明する仕組みはない。人間の一意性が必要な規模では認証・追加レート制限・必要に応じたBot対策を追加する。架空の人数やクライアント指定の人数は使用しない。
- セッションは30日間有効。ゲストの復旧・他端末への引き継ぎ・メール/SNS認証・全端末ログアウト・アカウント削除UIは未実装。
- SQLiteは単一プロセス向け。DBアクセスと通信モジュールは分離しているが、PostgreSQL等への移行にはスキーマとトランザクションの変更が必要。大規模向けinterest management、空間インデックス、共有presence、複数ワーカーは今後の課題。
- 同じワールドにいる人のマップ位置と公開プロフィールを送信。非公開設定は閲覧投稿と保存・いいねからの共通点・マッチ度の公開を止めるもので、アバター自体を隠す設定ではない。ブロック相手には個別の位置・プロフィールを送らない。閲覧人数は匿名集計値なのでブロック相手を含みうる。
- 地形は探索のための装飾で、建物との衝突や障害物回避の経路探索は未実装。クリック直線移動、歩行、座標への案内、エリアへのショートカットは使用可能。仮想ジョイスティックはタップ移動で基本操作を満たすため未追加。
- チャット履歴は最新100件。ページ送り、未読件数の永続化、プッシュ通知、添付ファイル、既読は未実装。パーティ内のWebRTC音声は実装済み。交流申請と新着メッセージの画面内通知は実装済み。
- YouTube公式iframeは実装済みだが初期動画は未確認の設定サンプル。TikTokは公式Player v1、Xは出典リンクとして表示。外部フィードの自動収集やメタデータ取得は未実装。外部画像はHTTPS URL指定方式でアップロードUIはない。
- テスト用のキー・DBは独立した一時領域に作成。実運用データやキーでE2Eを実行しない。公開後は実動画・管理権限・モバイル実機・回線切断・複数ユーザー負荷を確認する。

## ルーム・外部URL・音声の運用

- 一般ゲストによる外部URL登録はすぐ広場へ公開される。登録者の削除と管理者の削除・通報確認を使用できるが、公開規模に応じた投稿前モデレーションは追加が必要。タイトル・投稿者名は入力値であり、提供元による認証を示さない。
- 公開ルームの配置は公開情報。公開取り消し・ブロック時は訪問者を広場に戻す。非公開ルームのURLだけを知っていても所有者以外は入れない。
- 音声は承認済みの友達への招待と受諾、さらにマイク許可を経て参加。STUNは既定でGoogleの公開サーバー。異なる回線・制限されたNATではTURNを設定して実端末で確認する。HTTPSが必須（同一PCのlocalhostは例外）。既存の静的ホストだけでは友達と同じWALKに接続できない。
- TURN環境変数は `WALK_TURN_URL` / `WALK_TURN_USERNAME` / `WALK_TURN_CREDENTIAL`。認証済みの音声参加者に配る値として管理し、実運用では短命資格情報・帯域制限・監視を推奨。`npm run test:e2e:relay` のループバック専用設定・一時資格情報を外部公開用に転用しない。
- 使い方・上限は [COMMUNITY.md](COMMUNITY.md) を参照。
