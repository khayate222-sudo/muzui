# WALKの運用

2026-10-19更新。公開準備の全手順は [RELEASE_RUNBOOK.md](RELEASE_RUNBOOK.md)、配置は [INTERNATIONAL_LAUNCH.md](INTERNATIONAL_LAUNCH.md)、アカウント・対応機能は [COMMERCIAL_FOUNDATION.md](COMMERCIAL_FOUNDATION.md)、バックアップは [BACKUP_AND_OPERATIONS.md](BACKUP_AND_OPERATIONS.md) を参照する。古い実装前の制約一覧に代えて、現在の状態をまとめる。

## 実装済み

- アカウント登録・復旧コード・他端末の失効・本人のデータ取得と削除。パスワードと復旧コードを両方失った場合の自動復旧、メール本人確認は未実装。
- 実セッションに基づく移動・オンライン人数・投稿を開いている人数。一般公開への同意がない閲覧者の名前・閲覧位置を他人へ配信しない。同じユーザーのタブを重複集計せず、現実の活動中の分身もオンライン・閲覧人数へ加えない。
- 承認制チャット、ブロック、通報、管理者による対応状態・メモ・利用停止と解除。通報の外部通知、自動判定、24時間以内の対応保証はない。
- 個人ルームは非公開が既定。公開取消・ブロック時は訪問者を駅へ戻す。公開URLを知っているだけで非公開ルームへ入れない。
- 同意付き同期視聴は対象のWALK動画のみ。外部SNSは公式プレーヤーまたは元投稿リンクで、外部動画の同期・映画配信は未実装。
- 公開モードでは、直接投稿・添付・外部URL登録に無料アカウントを必要とする。投稿の添付と活動写真は合計200MB、直接投稿は100件まで。
- 直接投稿の識別子付き再試行と削除後の復活防止。端末ごとの下書き復元。すべての書き込みを重複防止したものではなく、自動送信はしない。

## 公開前に運営者が行うこと

- 運営者・問い合わせ先・対象年齢・保存期間と正式文書を確定し、公開HTTPS先を用意する。既存の`.env`、DB、投稿、バックアップを削除しない。
- SQLiteとメディアを永続化する単一プロセス構成で配備する。任意のX-Forwarded-Forを信用しない。複数ワーカー・複数の独立DBによる分散構成は未対応。
- 実際の国・回線・実機で動画、WebSocket、音声とマイク終了を確認する。本番ComposeのSTUN既定はoff。外部回線の音声には運営するTURNを用意し、ループバック試験の資格情報を転用しない。
- 外部コンテンツの利用条件、公開・埋め込み・地域制限、作者と出典を確認する。ライブラリの過去の冒頭再生確認は、現在の全編や各国・実機での再生保証ではない。
- 日々の通報確認と障害時の連絡担当、監視、容量、バックアップ・復元訓練、保持期間と破棄を決める。チャットはSQLiteに保存し、E2E暗号化ではない。
- 依存監査、公開規模に応じた負荷・悪用対策を確認する。ゲストを別端末まで同一人物と証明するものではない。チャットのページ送り・プッシュ通知・既読・添付は未実装。
- ネイティブ実機、署名、ストアの年齢・データ申告を行う。課金・広告報酬、自由建築・経済・カジノを有効化したとは扱わない。

`npm run release:report` は秘密の値を出さずに設定と残る手作業を表示する。`-- --probe` を付けた公開エンドポイント確認も、実機・権利・運営体制・ストア審査の代わりではない。
