# 抖音・快手から、好きな世界へ（2026-10-17）

ユーザーの決定：YouTubeを優先するのではなく、中国・海外のSNSを供給元にしたい。最初は **抖音＋快手の短い動画** を優先する。既存のYouTube機能は維持するが、今回の入口はこの二つを前面にする。

環境公開後の更新：抖音は明示的な確認後に公式プレーヤーを開く機能を追加した。通常の動画URLは動画の棚にも含める。快手は引き続き元投稿リンクで、アカウント連携には登録・権限・OAuthが必要。[最新の対応範囲・公式資料・実接続の結果](DOUYIN_PLAYER.md)を参照。以下は初回のリンク登録時点の記録である。

## 初回に実装したこと（リンク登録）

「投稿を集める」で、抖音・快手の共有メニューからコピーした文章とリンクをそのまま貼り付けられる。URLは一つだけ受け付け、題名・元の投稿者・紹介文・ジャンル・奥の世界を確認して公開し、お気に入りへ保存する。動画ファイル・画像・題名を勝手に取得しない。

| サービス | 受け付ける入口 | WALKでの扱い |
| --- | --- | --- |
| 抖音 / Douyin | `www.douyin.com/video/<数値ID>`、ルートの `?modal_id=<数値ID>`、`www.iesdouyin.com/share/video/<数値ID>` | 同じ動画の通常URLへ正規化し、元のSNSで開く |
| 抖音の共有短縮リンク | `v.douyin.com/<コード>` | 短縮リンクのまま保存。移動先・動画・投稿者は未確認と明示 |
| 快手 / Kuaishou | `www.kuaishou.com/short-video/<ID>` | 元のSNSで開く投稿リンク |
| 快手の共有短縮リンク | `v.kuaishou.com/<コード>` | 短縮リンクのまま保存。移動先・動画・投稿者は未確認と明示 |

短縮リンクの大文字・小文字は維持する。トラッキング用クエリ・フラグメントは保存しない。短縮リンクをサーバーで展開せず、短縮リンクと通常URLが同じ動画かどうかも推測しない。同じ短縮コードや同じ通常URLは重複登録しないが、異なる短縮コードや通常URLとの同一性は未解決のため別投稿になる場合がある。

プロフィール・ライブ等の通常URL、偽ドメイン、HTTP、資格情報付きURL、非標準ポート、複数URLは拒否する。ただし短縮リンクの移動先は検査していないため、投稿以外へ転送される可能性も画面で説明する。短縮リンクが公開・安全・再生可能であると認定する機能ではない。

登録前に「元のリンクを確認」で別タブへ開ける。登録済みの投稿をもう一度登録した場合は、その投稿を保存して元の公開先へ開き、元の題名・作者・公開先を変えない。削除権限・ブロック・閲覧情報の公開同意は既存の仕組みを使う。

## 初回の範囲（その後の抖音対応は上記参照）

今回は **世界へリンクを持ち寄り、元SNSの投稿へ開く入口**。中国SNSの動画をWALK内のプレーヤーで再生する実装ではない。動画の棚・動画だけの次送り・一人向けの動画配置API・同期視聴の対象に、これらのリンクを混ぜない。実際の題名・作者・映像・画像を取得したとは表示せず、架空の外部動画や投稿者を初期データにも追加しない。

WALKの人数は、この投稿カードを開いている実際の利用者数。元SNSへ移動した後の再生・視聴時間・ログイン状態を観測する機能はない。公開に同意した人だけを名前付きで表示する。短縮リンクの登録だけでは、他サービスへ接続しない。

新着の自動収集、外部アカウント認証、公式プレーヤー、アプリ内の連続再生・同期、動画の保存・転載は未実装。抖音はTikTok、快手は海外向けKwai／SnackVideoと、同じURL・APIとして扱わない。既存のTikTok Playerへ抖音の動画IDを渡すこともしない。

## 公式連携を次に進める条件

最終目標は、WALKの街で短い動画を楽しめること。次の調査では提供元の公式開発プラットフォームで、第三者の公開動画を扱う権限、本人が許可した投稿の範囲、海外からの利用、Web／iOS／Androidに使える再生SDK・埋め込み・契約を確認する。ログインや地域制限を回避する取得処理は作らない。

使える公式再生方式が確認できた提供元から、少数の確認済み動画で縦画面・ログイン・削除／非公開・音声・広告・再生失敗を検証し、その後に動画の棚へ加える。公式の再生操作が得られない場合、同期できるとは約束しない。協力する投稿者がWALKへ直接提供する動画は別の供給経路として扱えるが、現時点で許諾や提供者を確保済みではない。

## 環境公開前の調査・通信の記録

今回、[抖音开放平台](https://open.douyin.com/)と[快手开放平台](https://open.kuaishou.com/)へ接続したが、クラウドのプロキシでCONNECT 403となり本文を取得できなかった。bilibili・小紅書・Blueskyの公式資料も403。この資料は最新の審査・取得枠・料金・利用可能地域をオンラインで再確認した調査結果ではない。人気の順位や利用者数を最新統計で確定したという主張もしない。

`cloud-environment-onboarding:setup` に沿い、既存設定を維持して以下をネットワーク設定の下書きへ追加保存した：`open.douyin.com`、`open.kuaishou.com`、`www.douyin.com`、`v.douyin.com`、`www.iesdouyin.com`、`www.kuaishou.com`、`v.kuaishou.com`。保存は適用ではない。環境設定で変更を確認・保存し、環境を公開した後に実接続を確認する必要がある。SDK等に別の接続先が必要なら、公式資料を確認してから追加する。
