# ロゴと上下のUIを、駅の世界へ

ユーザーが画像で指定したロゴ・上部の現在地と操作・下部のカテゴリーとスマホナビを更新した。箱庭の絵に加えて、操作にも「不思議な駅」の意匠を広げる段階。

## 実装したもの

- **ロゴ**：時計塔と入口、瓦屋根、葉を組み合わせた小さな駅舎。文字と「好きへ、寄り道。」を添える。読み込み・ログインの復帰・利用停止時にも同じロゴを使う。
- **上部**：現在地のタイトル、投稿・活動の紙のタブ、切符の形をした「行き先」。ベージュと茶色の枠、セージのインク、細い二重線を使い、駅の絵と色だけでなく形も揃える。
- **階層と入口**：実際の現在地と階層を紙の案内にまとめる。入口の並びは点線と区切りを使い、独立した角丸カードが増えすぎないようにする。奥へ進む操作・戻る操作・横スクロールを保持。
- **カテゴリー**：広場・音楽・動画・アート・ミーム・ゲーム・アニメを共通の線画へ置き換える。以前のプラットフォーム依存の絵文字は、この移動操作では使わない。
- **スマホ下部**：駅舎、折り畳んだ地図、しおり、手紙、実際の自分の肖像。手帳のような紙と区切りに統一し、選択中の項目には淡い緑の印を付ける。既存の「ホーム」「探す」「保存」「つながり」「あなた」の名前と機能を保持。

図形はSVG、文字や接続人数・現在地・通知・ボタンは実際のUI。表示を一枚の画像に固定していない。新しい外部画像・フォント配信・依存パッケージは追加していない。世界の番号や架空の利用人数も追加していない。

## 読み取りとスマホ操作

320px / 390pxで、今回の上部操作・現在地・入口・カテゴリー・下部ナビは44px以上の押せる大きさを確保する。アイコンは装飾として読み上げから除き、操作の名前は文字と既存のラベルで伝える。現在のカテゴリーは選択状態も公開する。

上下の操作で地図が狭くなりすぎないようにし、横スクロールは行き先やカテゴリーの帯の中で行う。画面全体の横はみ出しを防ぎ、下のナビとOSのsafe-areaは既存の配置を保つ。キーボードのフォーカスは、スクロールする帯の中でも枠が見えるようにする。

既存の投稿・移動・ルームの権限、実際の閲覧者・同期視聴・活動の分身は別の状態のまま扱う。これらの保存形式や人数計算は、このUI更新では変更しない。

## 今回の範囲の先

エリアごとの大きな固有の街、共有世界の自由建築、骨格付きの歩行、経路探索、カメラの自動演出、ストア公開は引き続き別工程。今回の駅舎ロゴや線画はそれらが完成したことを示すものではない。
