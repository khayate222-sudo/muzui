## 再実行

```sh
cd walk
npm run typecheck
npm run lint
npm test
npm run build
npm run videos:verify
```

`videos:verify` は実通信を行い、未確認・503・429を成功にせず終了コード1で返す。今回のWALK内実接続は未確認のため、このコマンドが全件成功したとは記録しない。通信が安定した後の追加確認を残す。
