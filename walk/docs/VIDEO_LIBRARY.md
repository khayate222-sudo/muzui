## 実再生を確認した範囲

390×844の通常のChromiumから、一時DBで本物のWALKを起動。登録フォーム、投稿を開く操作、公式プレーヤーを開く操作、提供元の再生ボタンを使った。映像を読み込む準備が整うのを待ち、画面をタップして小画面用の中央再生ボタンを表示してから押す。これが、読み込み後も停止状態が続いていた以前の確認手順からの修正点である。

3回以上の実測で、映像サイズが正・エラーなし・再生中で、再生時刻が4秒以上進むことを成功条件とする。`video.play()`の強制実行、自動再生制限の無効化、模擬応答、動画のダウンロード・転載は行わない。HTMLやiframeのロード、題名取得だけでは再生成功としない。

**確認したのは、このクラウド環境のChromiumでの冒頭。全編・各国・iOS / Androidの実端末での再生保証ではない。** 現在の接続・ログイン・地域・広告・公開設定は提供元に従う。以前の503や停止状態の記録は、過去の検証として残す。最新の成功で過去の失敗を書き換えず、過去の失敗を現在の全件未確認とも扱わない。

過去の記録：[当初の公式iframe確認](verification/VIDEO_CHECKS_2026-10-17.json)、[再試行時の503](verification/VIDEO_QUALITY_CHECK_2026-10-17.json)、[前回の実装検証](VALIDATION_VIDEO_QUALITY_2026-10-17.md)。最新のWALK内確認は上の2つのJSONを参照。

## 見つける・見る・見られない場合

「今日の動画の棚」でWALK制作／海外の動画とジャンルを選べる。外部動画の表紙はジャンルの風景であり、実サムネイルを装わない。実測日・作者・長さと「開発環境で冒頭を確認」を表示し、いつでも必ず再生できるとは表示しない。

bilibiliは、検証したBV形式・通常URL・回（1〜100）から公式iframeを組み立て、`autoplay=0`で開く。任意のiframe HTMLを受け入れない。大画面・箱庭・窓辺の切り替えでプレーヤーを作り直さない。320px・390pxの窓辺でも再生ボタンが画面内に入る構成にする。

再生できないときは、明示的に読み直す、元SNSで開く、状況を書いて運営に知らせる操作を用意した。読み直すと再生位置は戻る。報告だけで投稿や保存を消さず、運営が既存の通報キューで確認する。

WALKの閲覧人数はその投稿カードを実際に開いている人の数で、外部の再生回数ではない。名前・アバターは公開同意のある人だけを表示する。外部動画の同期視聴、架空の閲覧者、フォロワー数の取り込みは追加していない。

## 安全に追加する

動画ごとの導入履歴で、新しい収録分だけを既存DBに追加する。旧版の16本は移行 `0010.sql` で導入済みとして引き継ぐ。同じURLの利用者投稿を重複作成せず、既存の題名・作者・配置・お気に入り・選定順を上書きしない。削除した収録動画を再起動で復活させない。

新しい投稿の配置は、同じ世界のボードが画面上で重ならない空間を探す。既存の配置は動かさない。すでに重なったボードはタップ位置から近い中心を選ぶ。非常に密な世界で空間が足りない場合は最大の隙間を使うため、無制限の本数を完全に重ねず表示する保証はない。投稿の一覧・検索からも開ける。

```sh
cd walk
npm run build
# 初期ライブラリを、本物のWALKと公式プレーヤーで確認する
npm run videos:verify
# 実在する候補のJSONを指定する場合（1〜50件）
npm run videos:verify -- --input /path/to/candidates.json --output artifacts/check.json
```

候補の形式は `[{"url":"実際に発見した投稿URL","title":"確認用の題名","authorName":"元の作者","genre":"art"}]`。利用中の `data/` は初期化せず、一時DBを使う。結果と画像は `artifacts/` へ保存し、未確認があれば終了コード1にする。429・503で残りを停止し、予定・実行済み・未実行・停止理由を記録する。実行だけでは自動収録しない。成功した候補の内容と出典を確認してから収録データへ追加する。

抖音・快手の優先は維持する。抖音は公式の再生情報APIとプレーヤーの入口を実装済みだが、公開サンプルでの実再生は未確認。快手は元SNSリンクとして開き、認証連携・自動収集・WALK内プレーヤーを実装済みとは扱わない。[抖音の実装と制限](DOUYIN_PLAYER.md)、[中国SNSのリンク登録](CHINESE_SHORT_VIDEO_SOURCES.md)も参照。
