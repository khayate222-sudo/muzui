# muzui studio

個人ネイルサロン向けの1ページサイト制作サービス。販売ページ、編集できる架空サロンのデモ、相談文作成とメール導線、確認用HTMLの保存機能を備えています。

## 開発

Node.js 22以上（検証環境: 24.19.0）。本番サーバーは標準ライブラリのみ。Playwrightは開発時のブラウザ検証用です。

```sh
cd /workspace/muzui
npm ci --cache /tmp/muzui-npm-cache
npm test
npm run build
npm start
```

`npm run dev` は変更時にサーバーを再起動します。既存のチェックアウトを使います。クラウドタスクは既に独立した環境なので、新しいGit worktreeは不要です。

`npm run test:e2e` は `/usr/bin/chromium` を使い、別の一時ポートでブラウザチェックを実行します。別のChromiumを使う場合は `CHROMIUM_PATH` を指定します。結果画像は無視対象の `artifacts/` に出力します。

## ページ

- `/`: 制作費5,000円の販売案内、制作範囲、相談フォーム
- `/demo`: サロンのサンプル。店名・料金・写真・予約先を変更し、HTMLを保存
- `/terms`: サービス条件、情報の扱い、正式な受注前に確定する事項
- `/config.json`: 公開する相談先URLのみ。入力情報の収集APIはありません

公開メールアドレスは `site.config.json` の `contactUrl` に設定済みです。`CONTACT_URL` でHTTPSの相談先や `mailto:` に上書きできます。これは公開情報であり、認証情報は入れません。`PORT` の既定値は3000です。支払い情報、アカウント情報や認証情報をコードに保存しないでください。

## 公開

`npm run build` の出力 `dist/` はバックエンド不要の静的サイトです。ルート直下に公開できる静的ホストで使えます。サブディレクトリへの配置には、絶対パスのリンク調整が必要です。

Netlifyなどの静的ホストに **distの内容** を公開します。Netlifyにはセキュリティヘッダーを設定する `_headers` も含めています。他のホストでは同等のヘッダー設定を行ってください。単純な全パスからindex.htmlへのSPAリダイレクトは不要です。

GitHub連携で公開する場合は、`delivery/muzui-launch` ブランチを選択します。ルートの `netlify.toml` でビルドコマンドを `npm run build`、公開先を `dist`、Node.jsを24に設定しています。生成済みの公開用ZIPには、ビルド不要・公開先 `.` の設定を含めています。Hugoは使用しません。ログに `$ hugo` が表示される場合は、このサイト以外の設定やファイルが読み込まれています。Netlifyの対象リポジトリ、ブランチ、Base directoryとnetlify.tomlを確認してください。

公開後は `/`、`/demo`、`/terms` を開き、相談先のメールアドレスと相談文が正しいことを確認してください。メールアプリがない端末では、相談文をコピーし、受付メールアドレス宛てに手動送信できます。コード側のテストはメールの受信・配達まで確認したものではありません。

## 販売開始前

相談窓口は接続済みですが、公開・決済・販売者情報の確定は未実施です。サイト公開だけで売上が発生するわけではありません。実際の受注前に、販売者の必要な表示、支払方法、納期、キャンセル・返金条件を確定してください。`docs/SALES_KIT.md` に、公開から最初の相談・受注までの手順と募集文をまとめています。

デモの写真アップロードは端末内で処理し、軽量化したWebPを保存用HTMLに埋め込みます。情報や写真をサーバーに送信しません。保存したデモは確認用のサンプルです。制作プランで売る価値は、店舗の情報整理・内容確認・写真の組み込み・修正・納品対応です。
